# Aplicación de Recetas IA  v0.0.1.

Esta es una aplicación de Recetas para el uso del día al día

> Esta es una aplicación [Next.js](https://nextjs.org) generada con el comando de [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Iniciar aplicación

Codigo para correr la aplicación:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

La aplicación por defecto corre en el la dirección [http://localhost:3000](http://localhost:3000) de manera local.

La aplicación puede requerir el uso de diferentes servicios para la generación de recetas.

Este proyecto utiliza la fuenta de [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) para automaticamente reducir la carga con [Geist](https://vercel.com/font), una nueva fuente de vercel.

## Deploy on Vercel

La aplicación se despliega en vercel.
